## 2024-11-08 - Icon-only buttons require manual tooltip and latch state wiring
**Learning:** In ProcessCommander, icon-only buttons (like `BS_OWNERDRAW` containing only icons/emoji such as the `📊` usage toggle) lack native accessible labels and automatic latched-state rendering. Adding a tooltip via `TOOLINFOW` provides the ARIA-label equivalent, but dynamically updated tooltips (e.g. "Show" vs "Hide") require manual integration into the main update loop (`UpdatePanelToggleLabels`) and explicit invalidation (`InvalidateRect`) to sync visual and semantic state.
**Action:** Whenever introducing or discovering an icon-only `BS_OWNERDRAW` toggle button in a Win32 application, check the `TOOLINFOW` initialization and `InvalidateRect` logic to ensure both accessibility labels and visual pressed states are dynamically maintained.
